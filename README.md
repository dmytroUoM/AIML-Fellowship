# AI/ML Fellowship Projects

This repository contains practical Artificial Intelligence (AI), Machine Learning (ML), computer vision, and industrial image-processing projects developed as part of the AI/ML Fellowship programme.

The projects focus on applying AI techniques to industrial tomography data, image enhancement, segmentation, reconstruction, automation, and reproducible research workflows.

---

## Project 2

### AIML-Driven Super-Resolution and Volumetric Reconstruction for Mixing Tanks

Project 2 investigates methods for improving industrial resistance-tomography images and reconstructing volumetric representations of mixing tanks.

The project explores traditional image-processing techniques and machine-learning approaches for cleaning images, generating segmentation datasets, training models, running inference, and producing visual reconstructions.

### Main areas

- AVI video processing
- Image extraction and cropping
- Artefact removal
- Background transparency generation
- Edge smoothing and refinement
- Real-ESRGAN super-resolution
- Synthetic dataset generation
- TinyUNet segmentation training
- AI inference and explainability
- Volumetric reconstruction
- Experimental model evaluation

### Objectives

- Improve tomography image quality
- Evaluate AI-assisted image enhancement
- Compare classical and AI-based workflows
- Support future digital-twin and monitoring applications
- Develop reproducible AI research pipelines

## Project 3

### AI Tomography Processing Pipeline

Project 3 is a modernised AI image-processing platform built around a modular pipeline architecture.

The project converts AVI video recordings into image datasets and provides automated processing stages based on TinyUNet segmentation, LaMa image inpainting, and Real-ESRGAN super-resolution.

The system supports local execution and Docker-based deployment while maintaining a consistent processing workflow across environments.

### Main areas

- Frame extraction from AVI files
- TinyUNet segmentation inference
- LaMa image inpainting
- Real-ESRGAN super-resolution
- Experiment management
- Containerised deployment
- Centralised logging
- Automated processing pipelines
- Reproducible AI workflows

### Objectives

- Automate tomography image preparation
- Improve image quality for analysis and visualisation
- Investigate AI-assisted reconstruction techniques
- Support research, education, and experimentation
- Provide a scalable platform for future AI workflows
